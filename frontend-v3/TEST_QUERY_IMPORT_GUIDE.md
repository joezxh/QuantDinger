# 数据源测试查询和导入功能使用指南

## 概述

数据源管理界面新增了两个核心功能模块：
1. **测试查询** - 验证数据源API连接可用性和查询功能
2. **导入/导出** - 批量导入导出数据源配置，支持模板库

---

## 🧪 测试查询功能

### 访问路径

访问 `/data-source` 页面，点击 **"测试查询"** 标签页。

### 功能特性

#### 1. 批量测试所有数据源

**操作步骤**:
1. 点击 **"批量测试所有数据源"** 按钮
2. 系统会并行测试所有数据源的连接状态
3. 实时显示测试进度和结果

**测试内容包括**:
- ✅ API连接可用性
- ✅ 响应时间测量
- ✅ 错误信息捕获
- ✅ 健康状态更新

**进度显示**:
```
正在测试 15/23 个数据源...
[████████████████████░░░░░░] 65%
```

#### 2. 单个数据源测试

**操作步骤**:
1. 在数据源列表中找到目标数据源
2. 点击操作列的 **"测试"** 按钮
3. 查看测试结果

**结果显示**:
- 状态：成功（绿色）/ 失败（红色）
- 响应时间：< 200ms（绿色）、200-500ms（橙色）、> 500ms（红色）
- 错误信息：失败时显示详细错误

#### 3. 查询测试

**操作步骤**:
1. 在测试通过的数据源上点击 **"查询测试"**
2. 在弹出的对话框中输入查询参数（JSON格式）
3. 点击 **"执行查询"**
4. 查看查询结果和数据预览

**查询参数示例**:

```json
// 加密货币数据源
{
  "symbol": "BTC/USDT",
  "timeframe": "1d"
}

// 股票数据源
{
  "symbol": "AAPL",
  "period": "1mo"
}

// 搜索引擎
{
  "q": "AI technology trends",
  "num": 10
}

// 宏观经济
{
  "series_id": "GDP",
  "frequency": "Q"
}
```

**查询结果显示**:
- 响应时间
- 返回数据条数
- 数据预览（JSON格式）
- 错误信息（如果失败）

### 统计概览

顶部显示4个统计卡片：
- **总数据源**: 系统中的数据源总数
- **测试成功**: 健康状态为"healthy"的数量
- **测试失败**: 健康状态为"unhealthy"的数量
- **平均响应时间**: 所有已测试数据源的平均响应时间

### 响应时间颜色编码

| 颜色 | 响应时间 | 状态 |
|------|---------|------|
| 🟢 绿色 | < 200ms | 优秀 |
| 🟠 橙色 | 200-500ms | 一般 |
| 🔴 红色 | > 500ms | 较差 |

## 📥 导入/导出功能

### 访问路径

访问 `/data-source` 页面，点击 **"导入/导出"** 标签页。

### 导入功能

#### 支持的格式

- ✅ **JSON** - 推荐格式，支持完整配置
- ✅ **CSV** - 简单配置导入
- ✅ **YAML** - 需要安装 js-yaml 库

#### 导入流程（3步向导）

**步骤1: 选择文件**

1. **拖拽上传**: 将文件拖到上传区域
2. **点击上传**: 点击选择文件
3. **从模板导入**: 选择预定义模板

**文件要求**:
- 格式：.json, .csv, .yaml, .yml
- 大小：不超过 10MB
- 编码：UTF-8

**步骤2: 预览配置**

系统会解析文件并显示：
- 数据源列表
- 配置有效性验证
- 类别标签

**操作**:
- 勾选需要导入的配置
- 取消勾选不需要导入的配置
- 查看验证状态（有效/无效）

**步骤3: 确认导入**

配置导入选项：

1. **导入模式**:
   - 仅创建新配置 - 跳过已存在的数据源
   - 更新已存在的配置 - 仅更新已有数据源
   - 创建或更新（推荐）- 智能处理

2. **启用导入的数据源**: 导入后自动启用

3. **同时导入API密钥**: 如果文件包含密钥信息

4. **同时导入限流配置**: 如果文件包含限流配置

点击 **"开始导入"** 执行导入。

#### 导入进度

导入过程中显示：
```
正在导入 8/15 个配置...
[████████████░░░░░░░░░░░░] 53%
```

#### 导入结果

导入完成后显示：
- 成功数量
- 失败数量
- 失败原因

### 导出功能

**操作步骤**:
1. 点击 **"导出配置"** 按钮
2. 系统自动下载 JSON 文件
3. 文件名格式：`data-sources-YYYY-MM-DD.json`

**导出内容**:
- 所有数据源配置
- API连接参数
- 市场类别
- 启用状态
- 备注信息

**导出示例**:
```json
[
  {
    "id": 1,
    "source_code": "crypto_ccxt",
    "source_name": "CCXT 加密货币交易所",
    "layer": "data_source",
    "market_categories": ["Crypto"],
    "enabled": true,
    "load_balance_strategy": "round_robin",
    "config_json": {
      "base_url": "https://api.coinbase.com",
      "timeout_sec": 10,
      "retry_count": 3
    },
    "notes": "主要加密货币数据源"
  }
]
```

### 模板库

点击 **"模板库"** 按钮打开预定义模板集合。

#### 可用模板

| 模板名称 | 说明 | 包含数据源 |
|---------|------|-----------|
| 加密货币数据源 | CCXT、CoinGecko等 | 2-3个 |
| 美股数据源 | yfinance、Finnhub等 | 2-3个 |
| 搜索引擎数据源 | Google、Baidu、Bing等 | 3-5个 |
| A股数据源 | AKShare、Tushare等 | 2-3个 |
| 宏观经济数据源 | FRED、IMF、OECD等 | 5-7个 |
| 新闻数据源 | NewsAPI等 | 1-2个 |

**使用模板**:
1. 点击模板卡片
2. 自动加载模板配置
3. 进入预览步骤
4. 确认后导入

#### 模板配置示例

**加密货币模板**:
```json
[
  {
    "source_code": "crypto_ccxt",
    "source_name": "CCXT 加密货币交易所",
    "layer": "data_source",
    "market_categories": ["Crypto"],
    "enabled": true,
    "load_balance_strategy": "round_robin",
    "config_json": {
      "base_url": "https://api.coinbase.com",
      "timeout_sec": 10,
      "retry_count": 3
    }
  }
]
```

### 导入历史

显示所有导入操作的历史记录：

**字段说明**:
- 导入时间: 操作执行时间
- 文件类型: JSON/CSV/Template
- 导入数量: 成功/总数
- 状态: 成功/部分成功/失败
- 操作: 查看详情

**查看详情**:
点击 **"查看详情"** 查看：
- 导入概要信息
- 每个数据源的导入结果
- 失败原因（如果有）

## 📋 JSON 配置格式规范

### 完整配置示例

```json
{
  "source_code": "search_google",
  "source_name": "Google Search API",
  "layer": "data_source",
  "market_categories": ["News", "Alternative"],
  "enabled": true,
  "load_balance_strategy": "round_robin",
  "config_json": {
    "api_key_env": "GOOGLE_SEARCH_API_KEY",
    "api_key_required": true,
    "base_url": "https://www.googleapis.com/customsearch/v1",
    "timeout_sec": 10,
    "retry_count": 3,
    "rate_limit_per_min": 100
  },
  "notes": "Google自定义搜索API"
}
```

### 必填字段

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| source_code | string | 唯一标识 | "search_google" |
| source_name | string | 显示名称 | "Google Search API" |
| layer | string | 数据层级 | "data_source" |

### 可选字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| market_categories | array | [] | 市场类别 |
| enabled | boolean | true | 启用状态 |
| load_balance_strategy | string | "round_robin" | 负载均衡策略 |
| config_json | object | {} | API连接配置 |
| notes | string | "" | 备注说明 |

### 配置验证规则

```javascript
// 有效的配置必须包含：
{
  source_code: /^[a-z_]+$/,  // 只包含小写字母和下划线
  source_name: /.+/,          // 非空
  layer: /^(data_source|data_provider|fundamental|sentiment|collector)$/
}
```

## 🐛 常见问题

### Q1: 批量测试卡住不动？

**原因**: 某个数据源响应超时

**解决**:
1. 等待超时（默认30秒）
2. 取消测试
3. 单独测试问题数据源
4. 检查网络连接

### Q2: 导入失败，提示"配置无效"？

**原因**: JSON格式错误或必填字段缺失

**解决**:
1. 检查JSON格式是否正确
2. 确认包含source_code、source_name、layer
3. 使用JSON验证工具检查格式
4. 参考配置格式规范

### Q3: 查询测试返回空数据？

**原因**: 查询参数不正确或API Key无效

**解决**:
1. 检查查询参数格式
2. 验证API Key是否配置
3. 查看错误信息
4. 参考API文档

### Q4: 导出的文件无法导入？

**原因**: 文件格式被修改

**解决**:
1. 不要修改导出文件的结构
2. 确保使用UTF-8编码
3. 检查JSON格式完整性
4. 重新导出尝试

### Q5: 模板导入后数据源未启用？

**原因**: 模板中enabled字段为false

**解决**:
1. 在导入步骤3勾选"启用导入的数据源"
2. 或者手动在数据源列表中启用

## 🔐 安全注意事项

1. **API密钥保护**: 
   - 导出的文件可能包含密钥引用
   - 不要将包含真实密钥的文件提交到Git
   
2. **权限控制**:
   - 导入/导出功能需要管理员权限
   - 普通用户无法访问

3. **文件验证**:
   - 系统会验证上传文件的格式和大小
   - 拒绝可疑文件类型

4. **操作日志**:
   - 所有导入操作都有历史记录
   - 可以追溯配置变更
