# 数据源管理界面 - 快速启动指南

## 🚀 5分钟快速上手

### 1️⃣ 安装依赖（如果还没有）

```bash
cd d:\projects\QuantDinger\frontend-v3
npm install
```

### 2️⃣ 启动开发服务器

```bash
npm run dev
```

服务器将在 `http://localhost:5173` 启动

### 3️⃣ 访问数据源管理页面

在浏览器中打开：
```
http://localhost:5173/data-source
```

### 4️⃣ 主要功能入口

| 功能 | 路径 | 说明 |
|------|------|------|
| 📋 数据源配置 | `/data-source` | 管理所有数据源的基本配置 |
| 🔑 API密钥管理 | `/data-source/keys?source_code=crypto_ccxt` | 管理指定数据源的API密钥 |
| ⚡ 限流配置 | `/data-source/rate-limit?source_code=crypto_ccxt` | 配置数据源的限流参数 |
| 💚 健康监控 | `/data-source/health` | 监控所有数据源的健康状态 |

---

## 📖 核心功能演示

### 场景1: 添加新的数据源

1. 访问 `/data-source`
2. 点击 **"新增数据源"** 按钮
3. 填写表单：
   - 数据源代码: `crypto_binance`
   - 数据源名称: `Binance 加密货币交易所`
   - 层: 选择 `data_source`
   - 市场类别: 选择 `Crypto`
   - API连接配置:
     ```json
     {
       "base_url": "https://api.binance.com",
       "timeout_sec": 10,
       "retry_count": 3
     }
     ```
   - 备注: `Binance交易所API，支持现货和合约数据`
4. 点击 **"确定"**

✅ 数据源添加成功！

---

### 场景2: 配置API密钥

1. 在数据源列表中，找到刚创建的 `crypto_binance`
2. 点击操作列的 **"密钥管理"**
3. 点击 **"添加密钥"**
4. 填写表单：
   - 密钥类型: `公共密钥`
   - 密钥别名: `Binance API Key #1`
   - 密钥值: `your-api-key-here`
   - 权重: `50`
   - 日调用限制: `10000`
   - 启用状态: 开启
5. 点击 **"确定"**

✅ API密钥配置成功！

---

### 场景3: 设置限流规则

1. 在数据源列表中，找到 `crypto_binance`
2. 点击操作列的 **"限流配置"**
3. 配置限流参数：
   - 限流策略: `令牌桶 (Token Bucket)`
   - 每周期请求数: `60`
   - 周期长度: `60` 秒
   - 突发容量: `60`
   - 最大并发数: `10`
   - 启用自适应限流: 开启
   - 错误时降速: 开启
   - 错误阈值: `5`
4. 点击 **"保存配置"**

✅ 限流规则设置成功！

---

### 场景4: 检查数据源健康

1. 访问 `/data-source/health`
2. 点击 **"全面健康检查"**
3. 等待检查结果（通常几秒）
4. 查看结果：
   - ✅ 绿色: 健康（响应时间 < 200ms）
   - ⚠️ 橙色: 较慢（200-500ms）
   - ❌ 红色: 异常（> 500ms 或错误）

✅ 健康检查完成！

## 🔧 常用操作速查

### 启用/禁用数据源

- 在 `/data-source` 页面
- 点击操作列的 **"删除"**
- 确认删除操作

⚠️ **注意**: 删除操作不可恢复！

## ⚠️ 注意事项

### 1. 权限要求
- 所有数据源管理功能都需要 **管理员权限**
- 普通用户无法访问这些页面

### 2. 后端依赖
- 确保后端服务正常运行
- 确保数据库已初始化（运行 `data_source_init.sql`）
- 确保API路径配置正确

### 3. 数据格式
- API连接配置必须是有效的 **JSON格式**
- 密钥值会加密存储，无法明文查看
- 限流参数必须在合理范围内

### 4. 性能建议
- 数据源数量较多时，使用搜索和过滤功能
- 健康检查会并发请求所有数据源，可能需要几秒
- 建议定期清理不再使用的数据源配置

## 🐛 常见问题

### Q: 页面显示空白？
**A**: 检查以下几点：
1. 后端服务是否运行
2. 浏览器控制台是否有错误
3. 是否已登录且有管理员权限

### Q: 保存配置失败？
**A**: 检查：
1. JSON格式是否正确
2. 必填项是否完整
3. 数据源代码是否唯一

### Q: 健康检查一直显示"未知"？
**A**: 
1. 点击"全面健康检查"按钮
2. 检查网络连接
3. 查看后端日志

### Q: 如何返回上一页？
**A**: 
1. 点击页面左上角的 **"返回"** 按钮
2. 或使用浏览器的后退按钮
