# 数据源管理前端界面开发总结

## 技术架构

### 前端技术栈
- **框架**: Vue 3.4+ (Composition API)
- **语言**: TypeScript 5.3+
- **UI库**: Ant Design Vue 4.1+
- **路由**: Vue Router 4.2+
- **HTTP**: Axios (封装在 utils/request.ts)
- **构建工具**: Vite 5.0+

### 设计模式
- **组件化**: 每个功能模块独立组件
- **路由驱动**: 通过路由参数传递上下文
- **响应式**: Composition API 响应式系统
- **类型安全**: TypeScript 全量类型定义
- **API封装**: 统一的请求拦截和错误处理

## 与后端集成

### 后端API路径
```
/api/data-sources/                      # 数据源配置
/api/data-sources/{code}/toggle         # 启用/禁用
/api/data-sources/health/{code}         # 健康检查
/api/data-sources/{code}/api-keys       # API密钥
/api/data-sources/{code}/rate-limit     # 限流配置
```

### 数据格式
- 请求：JSON格式
- 响应：统一格式 `{ data: {...}, error: string }`
- 错误处理：HTTP状态码 + 错误信息

### 安全机制
- API密钥加密存储（AES-256-GCM）
- 管理员权限验证
- CSRF保护（后端实现）
- 请求频率限制（后端实现）
